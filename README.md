# KOBYLA HAS WAKEN UP 2099 / КОБЫЛА ПРОСНУЛАСЬ 2099

Публицистическая визуальная новелла в киберпанк-сеттинге. Сектор 0, кислотный дождь,
Бункер-7 и проект КОБЫЛА-99 — автономный био-нейронный демон, запечатанный в 2075 году
и проснувшийся.

## 🎃 Хоррор-издание (DREAD ENGINE v5 — BRUTAL)

**Нагнетание, а не только скримеры.**
- **Движок страха (Dread Engine)**: ужас копится с каждым шагом вглубь бункера —
  растёт громкость низкого дрона, ускоряется сердцебиение, густеют шёпоты, чаще стуки,
  дальние крики, ноты «музыкальной шкатулки», скрежет. При высоком уровне страха —
  фейковые вспышки, мерцающие надписи («НЕ ОБОРАЧИВАЙСЯ», «ОНА СЛЫШИТ ТВОЁ СЕРДЦЕ»),
  силуэт кобылы в углу экрана, красная тонировка.
- **Скримеры с подводкой**: перед каждым скримером — райзер (нарастающий звук) и сжатие
  виньетки, затем удар: крик + морда кобылы на весь экран + тряска + вспышка.
- **Звук (Web Audio)**: низкие дроны, суб-райзеры, крики, визги, рыки, шёпоты, дыхание,
  сердцебиение, стуки в стену, скрежет металла, далёкие крики, «музыкальная шкатулка».
- **Кульминация**: при входе в зал с чанами (узел `BIO_HORROR`) — «КОБЫЛА ПРОСНУЛАСЬ.»:
  провал в черноту → крик → морда кобылы → тряска → красная вспышка → глитч-текст → двойная
  вспышка (морда → пустота с глазами). После — бункер «дышит» в страхе.
- **МУЗЫКА БОЛЬШЕ НЕ УБИВАЕТ СКРИМЕРЫ.** Музыкальный движок теперь идёт через
  мастер-шину громкости: в хоррор-зонах музыка приглушается до 10%, а в момент удара
  скримера режется в НОЛЬ — тишина перед ударом, и только потом крик+импакт.
- **ФИНАЛЬНЫЕ СКРИМЕРЫ в каждой концовке — теперь гарантированно.** (раньше могли не
  срабатывать из-за раннего `return` в ветке концовки; теперь `horrorCheck()` вызывает
  прямое `horrorEnding()` для финалов). Срабатывают на ~4.3 с после появления экрана
  концовки — раньше и жёстче. Структура: шёпот → статика → глитч → провал в черноту →
  ИМПАКТ + крик + морда (780мс) + тряска 50px + стробоскоп + шторм помех + фраза →
  вторая вспышка глаз → третья вспышка пустоты → силуэт в углу → сердцебиение → музыка
  возвращается.
  У каждого финала свой скример: `ВАЛЮТА СТАБИЛЬНОСТИ` — взгляд вплотную + «Я ПОДОЖДУ.»;
  `НЕЙРОННОЕ ВОЗНЕСЕНИЕ` — оскал + «МЫ — ОДНО.»; `АБСОЛЮТНЫЙ НОЛЬ` — пустота с глазами +
  «ТЫ УНИЧТОЖИЛ МЕНЯ, НЕ ПОНЯВ МЕНЯ.»; `ЭРА АЛГОРИТМА` — бледный череп + «ОНА УЖЕ ВЕЗДЕ.».
  Многоступенчатая структура: шёпот → статика → глитч → провал в черноту → КРИК + морда +
  тряска + вспышка + фраза → вторая вспышка глаз → сердцебиение.
- **Семь скример-изображений** одной и той же кобылы: морда (крик), пустота с глазами,
  оскал, глаза крупным планом, бледный череп, **скачущая прямо на камеру**, **взгляд вплотную**
  (в `_assets/`). «ПРОБУЖДЕНИЕ» теперь использует «скачущую» кобылу + шторм помех.
- **Помехи не мешают читать**: из шумового холста вырезается область текста
  (`story-container`) — статика остаётся на фоне и портрете, но не на тексте.
- **Кнопки**: `👁 СКРИМЕРЫ: ВКЛ/ВЫКЛ` и `🐴 ПОБУДИТЬ` (ручной скример в любой момент).
- Исправлен квадрат свечения у глаза: `eye-glow-overlay` больше не использует box-shadow
  (только мягкое радиальное свечение).
- Расписание событий — `HORROR_EVENTS`, механика страха — `HORROR` в `build_horror.py`.

## Как пересобрать

```bash
# расширенная игра -> kobyla_has_waken_up_expanded.html
python3 build_expanded_html.py
# роман внутрь игры -> kobyla_has_waken_up.html
python3 embed_novel.py
# хоррор-слой поверх -> kobyla_has_waken_up.html
python3 build_horror.py
# сценарий -> KOBYLA_HAS_WAKEN_UP_SCRIPT.md
python3 gen_script_md.py
```

## Стиль

Хлёсткая публицистика. Короткие фразы. Факты. Смета и аналитические выводы.
Экшен, драма и немного хоррора — по месту и по делу. Картина (тёмная механическая
кобыла в алом кольце) — центральный фундамент и не менялась ни в одном издании.

## Игра

Откройте `kobyla_has_waken_up.html` в браузере. RU/EN — кнопка в шапке.
Музыка и звуки — Web Audio API, без внешних файлов. Роман — кнопка «📖 РОМАН».
Скримеры — по умолчанию включены; отключаются кнопкой «👁 СКРИМЕРЫ».
